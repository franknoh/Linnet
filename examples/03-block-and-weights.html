Block and weights ​

A small stack of blocks — Linear, Mlp, a Model with a sub-array of layers — and the parameter manifest that a checkpoint must satisfy. It shows how structure in source becomes paths in a SafeTensors file.

Blocks own parameters, sub-blocks compose ​

Model<H, Inner, Layers, Vocab, T> declares sub layers: [Mlp<H, Inner, T>; Layers]; each Mlp declares two Linear sub-blocks; each Linear declares weight and an optional bias. static for layer in layers applies them in order at compile time.

Paths, not classes ​

text
layers.0.up.weight
layers.0.down.weight
...

linnet inspect --parameters prints the manifest: every leaf with its shape after the generics are substituted, and whether it is optional. Weights bind by these names, so there is no model class to keep in sync with the file.

Run it ​

bash
linnet inspect --parameters examples/03-block-and-weights/model.linnet
python
from linnet_torch import load
model = load("examples/03-block-and-weights/model.linnet",
             generics={"H": 8, "Inner": 16, "Layers": 2, "Vocab": 11, "T": "f32"},
             weights="weights/")          # SafeTensors named by the paths above

Source ​

model.linnet ​

linnet
// A small model built from nested blocks. Its parameter manifest lists every
// tensor a checkpoint must supply:
//
//     linnet inspect --parameters model.linnet
module examples.model

pub op rms_norm<*S: Shape, H: Dim, T: Float>(
    x: Tensor[*S, H; T],
    weight: Tensor[H; T],
    eps: f32,
) -> Tensor[*S, H; T] {
    let xf = cast<f32>(x)
    let mean_square[*s] = sum[h] xf[*s, h] * xf[*s, h] / cast<f32>(H)
    let scale[*s, h] = xf[*s, h] * rsqrt(mean_square[*s] + eps)
    return cast<T>(scale) * weight
}

pub block Linear<In: Dim, Out: Dim, T: Float = bf16> {
    param weight: Tensor[Out, In; T]
    param bias: Tensor[Out; T]? = none

    pub fn forward<*S: Shape>(x: Tensor[*S, In; T]) -> Tensor[*S, Out; T] {
        let y[*s, o] = sum[i] x[*s, i] * weight[o, i]
        return match bias {
            some(b) => y + b
            none => y
        }
    }
}

pub block Mlp<H: Dim, Inner: Dim, T: Float> {
    param norm_weight: Tensor[H; T]
    sub up: Linear<H, Inner, T>
    sub down: Linear<Inner, H, T>

    pub fn forward<*S: Shape>(x: Tensor[*S, H; T]) -> Tensor[*S, H; T] {
        let hidden = up.forward(rms_norm(x, norm_weight, 1e-5))
        return x + down.forward(max(hidden, 0.0))
    }
}

pub block Model<H: Dim, Inner: Dim, Layers: Dim, Vocab: Dim, T: Float = bf16> {
    param embedding: Tensor[Vocab, H; T]
    sub layers: [Mlp<H, Inner, T>; Layers]
    sub head: Linear<H, Vocab, T>

    pub entry forward<B: Dim, S: Dim>(tokens: Tensor[B, S; i32]) -> Tensor[B, S, Vocab; T] {
        let embedded[b, s, h] = embedding[tokens[b, s], h]
        var x = embedded
        static for layer in layers {
            x = layer.forward(x)
        }
        return head.forward(x)
    }
}
