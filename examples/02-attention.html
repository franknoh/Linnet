Attention ​

Scaled dot-product attention and a softmax written from scratch with index notation, reductions, and an explicit accumulation dtype. Nothing here is a primitive: softmax_last is max, exp, and sum over the last axis, and attention is two contractions around it.

Reductions with a dtype ​

linnet
let score[b, h, q, k] = sum<f32>[d] cast<f32>(query[b, h, q, d]) * cast<f32>(key[b, h, k, d])

sum<f32>[d] accumulates in f32 whatever T is, so bf16 inputs get f32 scores — the choice is in the source, not in a backend flag.

Softmax over the last axis ​

softmax_last<*S, N> subtracts the row maximum, exponentiates, and divides by the row sum; *S keeps it shape-generic. The standard library's std.nn.softmax::softmax is the same code, and a backend may replace it with a fused kernel (linnet explain shows when).

Commands ​

bash
linnet check examples/02-attention/attention.linnet

// Scaled dot-product attention expressed with typed index notation. Scores are
// accumulated in f32 regardless of the activation dtype.
module examples.attention

pub op softmax_last<*S: Shape, N: Dim>(x: Tensor[*S, N; f32]) -> Tensor[*S, N; f32] {
    let peak[*s] = max[n] x[*s, n]
    let shifted[*s, n] = exp(x[*s, n] - peak[*s])
    let total[*s] = sum[n] shifted[*s, n]
    let y[*s, n] = shifted[*s, n] / total[*s]
    return y
}

pub op attention<B: Dim, H: Dim, Q: Dim, K: Dim, D: Dim, T: Float>(
    query: Tensor[B, H, Q, D; T],
    key: Tensor[B, H, K, D; T],
    value: Tensor[B, H, K, D; T],
    scale: f32,
) -> Tensor[B, H, Q, D; T] {
    let score[b, h, q, k] = sum<f32>[d] cast<f32>(query[b, h, q, d]) * cast<f32>(key[b, h, k, d])
    let weights = softmax_last(score * scale)
    let mixed[b, h, q, d] = sum<f32>[k] weights[b, h, q, k] * cast<f32>(value[b, h, k, d])
    return cast<T>(mixed)
}
